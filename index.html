Local PDF question-answering (RAG)

In progress
Problem
Students have many PDFs and lecture notes and want answers with sources, without uploading files to an outside service.
Approach
  • Split PDFs into chunks, embed them, store them in Chroma
  • Retrieve the closest chunks and pass them to a local model on Ollama
  • Show the answer with file name and page number in a Streamlit chat
Challenges
  • Chunk size: compare settings on a fixed set of test questions
  • Hallucination: prompt the model to say when the answer is not in the context
  • Speed: quantized model and cached embeddings
